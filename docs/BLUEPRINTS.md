# Blueprints

Strava Daily Digest follows the shared blueprints in https://github.com/gadominas/app-blueprints.
The script's `BLUEPRINTS` block is the source of truth; this table mirrors it and adds deviations.

| Blueprint | Version | Since app version | Deviations |
| --- | --- | --- | --- |
| [in-app-updates](https://github.com/gadominas/app-blueprints/blob/in-app-updates-v1.0.0/blueprints/in-app-updates.md) | 1.0.0 | 1.10.0 | none |
| [settings](https://github.com/gadominas/app-blueprints/blob/settings-v1.0.0/blueprints/settings.md) | 1.0.0 | 1.10.0 | Sheet CSS is scoped under `#cfgsheet` because the digest already uses `.seg`, `.sec` and `.sw`; the app keeps its old colour names as aliases of the shared tokens; page code is ES5 to fit the page's template string; the detected athlete ID is still cached in the Keychain; the early-riser badge gradients are artwork, not theme colours; the athlete ID tunable has a digits-only pattern |
| [ai-configuration](https://github.com/gadominas/app-blueprints/blob/ai-configuration-v1.0.0/blueprints/ai-configuration.md) | 1.0.0 | 1.9.1 | AI settings and usage live in `strava-digest-ai-settings.json` and `strava-digest-usage.json`; no background AI jobs, so “What AI does” has no switch; page code is ES5 |
| [launch-screen](https://github.com/gadominas/app-blueprints/blob/launch-screen-v1.0.0/blueprints/launch-screen.md) | 1.0.0 | 1.12.0 | The digest loads a new page for every screen (boot, login, digest, refresh), so only the first page of a run carries the launch screen; if the feed arrives within 2.8 s the digest replaces it early. The logo has no sweep: its teal start dot is a Detail part coloured by one extra rule (`.splash .spStart`), and the rose finish dot keeps its dark cut-out ring with one more (`.splash .spPop` stroke). The name uses the app's `--display` font (`--sp-font`). The loading spinner's class was renamed from `.spin` to `.loadspin`, as the blueprint reserves the `sp` prefix |
| [widgets](https://github.com/gadominas/app-blueprints/blob/widgets-v1.0.0/blueprints/widgets.md) | 1.0.0 | 1.13.0 | `widgetRefreshMin` keeps its existing default of 15 min and range 15–120 (the blueprint suggests 30, 15–240), as Step 6 asks. The existing **Names on the widget** switch still applies: when it's off there are no name rows (large still shows PRs and early risers). `widgetModel()` reads `config.widgetFamily` to keep room for those two rows within the large size's 6. The caption says "Nobody posted yet" when nobody has posted today, and the empty state's footer says "Last checked <when>" when only an older day's snapshot exists. The Shortcuts `refresh` branch stays (it saves the snapshot too); the AI key migration moved into the app branch so a widget run writes nothing. The 1.12.0 summary file in iCloud (`strava-digest-widget.json`) is removed by the app on its first save; until the digest is opened once after updating, the widget shows the empty state |
